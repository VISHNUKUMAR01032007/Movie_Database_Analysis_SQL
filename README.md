# 🎬 South Indian Movie Database (SQL Project)

A SQL database of 1,878 South Indian movies (1960–2022), built to practice real-world SQL — JOINs, aggregation, grouping, and filtering.

### 📊 Overview

A MySQL database (movies_db) with a single movies table capturing release year, movie name, lead actor, language, and director.

Total records	1,878, 
Year range	1960 – 2022, 
Distinct actors	21, 
Languages	Malayalam, Tamil, Telugu, Hindi, Kannada, Bengali, English.

### 🧠 Concepts Practiced
JOINs, GROUP BY, HAVING, 
COUNT(DISTINCT ...) and aggregate functions, 
Filtering and sorting grouped results.

Normalize into actors, directors, movies tables.

### ✅ Conclusion

This project was a practical way to strengthen core SQL skills — JOINs, GROUP BY, HAVING, and aggregate functions — by working with a real, sizeable dataset instead of toy examples. Querying 1,878 movie records across six decades and multiple languages made concepts like COUNT(DISTINCT ...) and grouped filtering click in a way that theory alone doesn't. It also highlighted the value of good schema design and left clear next steps (normalization, richer data) for taking the project further.
